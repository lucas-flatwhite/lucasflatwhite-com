# Snake Experience: CPU 라이벌 대결 설계

날짜: 2026-07-20
대상: `src/lib/snake-experience.ts`, `src/data/site.ts`, `src/components/SnakeExperience.astro`

## 목표

플레이어와 같은 먹이를 두고 경쟁하는 CPU 스네이크를 추가해 홈페이지 게임에
대결 구도를 만든다.

## 규칙

- CPU 스네이크 1마리가 주황 계열 색으로 등장한다 (플레이어는 시안 계열).
- 플레이어와 CPU는 같은 스텝 주기로 움직이며, 같은 먹이를 두고 경쟁한다.
- 플레이어 머리가 CPU 몸/머리에 닿으면 플레이어 게임오버 (기존 퇴근 화면).
- CPU 머리가 벽/자기 몸/플레이어 몸에 닿으면 CPU가 죽고,
  `playfieldConfig.cpuRespawnMs`(2600ms) 후 빈 자리에서 길이 3으로 리스폰한다.
- 같은 틱에 같은 칸으로 향하는 head-to-head는 플레이어가 먼저 이동하므로
  CPU가 죽는다 (플레이어에게 관대한 규칙).
- CPU가 먹이를 먹으면 CPU만 성장하고 먹이가 재배치된다. 버스트 연출은
  플레이어의 보상으로 남긴다.

## CPU 인공지능

- 후보 방향 = 역방향을 제외한 3방향. 막힌 칸(벽·양쪽 몸)은 제외.
- 남은 후보 중 먹이까지의 맨해튼 거리가 최소인 방향 선택.
- 무작위 지터(±0.8)와 12% 확률의 무작위 선택을 섞어 완벽하지 않게 만든다.
- 모든 방향이 막히면 현재 방향 유지 (자연사).

## UI

- 상단 스코어: `length N · cpu M` 병기. 초기 마크업도 동일 형식.
- 게임오버 화면: `vs cpu M · 승/패/무` 라인을 추가하고 결과에 따라 색을 달리한다
  (승=민트, 패=주황, 무=크림). best/재시작 힌트는 그 아래로 내려간다.
- 배경 단어는 CPU 몸도 회피한다.

## 하지 않는 것

- CPU 다수 등장, 난이도 선택, CPU 전용 버스트 연출.
- 게임오버 후 CPU 단독 진행 (정지 화면에 최종 위치만 표시).

## 테스트

소스 계약 테스트에 CPU 관련 항목(타입, AI 함수, 리스폰 설정, 충돌 조건,
스코어 표기)을 추가하고 vitest / astro check / build / 브라우저 실플레이로 검증한다.
