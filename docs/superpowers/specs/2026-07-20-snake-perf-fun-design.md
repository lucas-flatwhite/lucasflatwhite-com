# Snake Experience: 성능 + 재미 개선 설계

날짜: 2026-07-20
대상: `src/lib/snake-experience.ts`, `src/data/site.ts`

## 목표

홈페이지 스네이크 경험을 (1) 프레임 비용을 크게 줄여 저사양/모바일에서도 부드럽게 돌아가게 하고, (2) 게임 루프에 고전 스네이크의 재미 요소(속도 상승, 최고 기록, 명확한 상태 피드백)를 더한다.

## 성능 개선

현재 데스크톱 기준 배경 단어가 1080개이며, 매 프레임마다 아래 비용이 발생한다.

1. **단어별 색상 문자열 생성** — `hsla(...)` 템플릿 문자열을 프레임당 1080회 생성.
   → 단어의 hue/alpha는 생성 후 불변이므로 `color` 문자열을 생성 시 1회 계산해 캐시한다.
2. **단어별 font/shadow 설정** — 모든 단어가 동일한 크기를 쓰므로 `ctx.font`·shadow 설정을 루프 밖에서 1회만 수행한다.
3. **배경 그라디언트** — 매 프레임 `createLinearGradient` 호출.
   → 캔버스 크기를 키로 캐시하고 리사이즈 시에만 재생성한다.
4. **단어-단어 겹침 해소** — 매 프레임 전체 정렬(`[...words].sort`) + 2패스 준-O(n²) 분리.
   단어는 앵커 주변을 느리게 표류하므로 매 프레임 풀 패스는 낭비다.
   → 뱀 회피/표류 보간은 매 프레임 유지하되, 정렬+겹침 분리 패스는 3프레임마다 1회로 스로틀한다.
5. **뱀 렌더링** — 세그먼트마다 `save/restore` + shadow 설정.
   → save/restore를 전체에서 1회로 줄이고 그림자는 머리 세그먼트에만 적용한다.
6. **devicePixelRatio 상한 2** — DPR 3 기기에서 픽셀 수를 2.25배 줄인다.
7. **score DOM 갱신** — 매 프레임 `textContent` 대입 → 텍스트가 바뀔 때만 대입.
8. **모바일 리사이즈 가드** — 현재는 모든 resize에서 게임 상태를 통째로 재생성한다.
   모바일 주소창 접힘(높이만 소폭 변화)으로 게임이 리셋되는 문제를 막기 위해,
   폭이 같고 높이 변화가 140px 미만이면 재생성을 건너뛴다. (재미에도 기여)

## 재미 개선

1. **속도 점증** — 길이가 늘수록 스텝 속도가 빨라진다.
   `speed = min(maxSpeed, baseSpeed + floor((length - 3) / speedRampEvery))`,
   `playfieldConfig`에 `maxSpeed: 12`, `speedRampEvery: 4` 추가.
2. **최고 기록** — `localStorage`(`lucas-flatwhite:best-length`)에 최고 길이를 저장.
   게임오버 화면에 `best N`을 표시하고 신기록이면 `new record!`를 강조한다.
   localStorage 접근은 try/catch로 감싸 프라이버시 모드에서도 안전하게 동작.
3. **재시작 힌트** — 게임오버 화면에 `enter / tap → restart` 힌트 추가.
   (기존에는 재시작 방법이 화면에 없었다.)
4. **일시정지 오버레이** — Space/Enter 일시정지 시 `일시정지 / paused` 표시.
   (기존에는 멈춘 것인지 렉인지 구분 불가.)
5. **WASD 지원** — 화살표 키에 더해 w/a/s/d로도 조작 가능.

## 하지 않는 것

- 게임 규칙(격자, 먹이, 버스트 연출)의 시각적 정체성 변경 없음.
- DOM 오버레이/버튼 추가 없음 — 기존 소스 계약 테스트가 금지함.
- 콤보/파워업 등 신규 메커니즘은 이번 범위에서 제외.
