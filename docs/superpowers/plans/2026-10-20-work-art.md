# Work Art Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the two Work excerpts with two pre-generated, self-contained SVG pictures: a woodcut plate for AI Timeline Log and a word-painted cat self-portrait for lucasflatwhite.com.

**Architecture:** Browser-side generators (plain ES modules ported from the approved mockups) run once in the installed Chrome via `playwright-core`. A Node build script then post-processes their output: it simplifies the plate's path and embeds subset fonts in the portrait. The resulting SVGs are committed under `src/assets/work/`, linked from the projects content collection with `image()`, and rendered as lazy `<img>` elements.

**Tech Stack:** Astro 5.18, TypeScript run directly by Node 22 (type stripping), vitest, `playwright-core@1.63.0` (dev), `subset-font@2.9.0` (dev), `@fontsource-variable/anybody` and `@fontsource-variable/noto-sans-kr` (already installed).

**Spec:** `docs/superpowers/specs/2026-10-20-work-art-design.md`

## Global Constraints

- Both SVGs: 720×480, root carries `xmlns`, `viewBox="0 0 720 480"`, `width="720" height="480"`. No external URL references besides namespace declarations.
- Ground colour `#16278a` (`--blue-deep`) on both. The plate's lines are `#f2f3f7`.
- Approved parameters are copied exactly from the mockups:
  - Plate: `scratchpad/.superpowers/brainstorm/85760-1792497428/content/atl-in-work.html`.
  - Portrait: B-3 in `self-portrait-b2.html`, seed 63.
  - Spec §3.1 and §3.2 list the values.
- Path simplification: RDP tolerance `0.15`, coordinates rounded to 0.5px, relative `l` commands.
- Embedded fonts: Anybody face `font-weight: 100 900; font-stretch: 50% 150%`. Noto Sans KR faces `font-weight: 100 900` plus the fontsource chunk's `unicode-range`.
- Subset text comes from the final SVG's text content plus a space, not from word pools.
- Gzip budgets: plate ≤ 40KB, portrait ≤ 100KB. Do not raise them; report instead.
- Copy rules (`tests/anti-slop.test.ts`): no en/em dashes in `src/`; sharp corners on the landing.
- Alt text:
  - AI Timeline Log: `A woodcut plate: a chat input with a blinking caret, its grain cut in rings that spread outward.`
  - lucasflatwhite.com: `A tabby cat seated in blue swirls after Van Gogh's 1889 self-portrait, every stroke a word that swells in weight and width.`
- No animation on the pictures. Remove the `excerpt-set` scroll effect.

## Review Focus

1. **A Hangul syllable missing from every embedded face** (e.g. a word added to a pool later) silently draws in a system font. The coverage test in Task 4 must fail.
2. **A standalone SVG without `xmlns` or `width`/`height`** renders blank in `<img>`, or leaves Astro without dimensions so the page shifts. Pinned by the Task 4 contract test and the `<img width height>` source assertion.
3. **The GitHub Pages build** (`/lucasflatwhite-com/` base) must point the images under the base path. Task 4 runs that build and greps `dist`.
4. **Regenerating with no changes must produce byte-identical files.** Otherwise every rerun is a noisy diff. Task 3 runs the build twice and checks with `git diff --exit-code`.
5. **WebKit draws the portrait** with the embedded faces and width axis, the same as Chrome. Task 3 compares screenshots from both engines against the approved mockup.

### Task 1: Plate generator and path simplifier

**Files:**
- Create: `scripts/work-art/engrave.js`
  - Browser ES module.
  - Exports `mulberry`, `nz`, `compose`, `vignette` and `engrave`, ported from `ai-timeline-log/src/engine/{random,compose,motif,engrave}.ts`, minus types.
- Create: `scripts/work-art/plate.js` exporting `plate(): string`.
  - Returns the raw path `d` of the approved plate.
  - It makes one recorder shared by all 64 buckets. The frame is `strokeRect(m, m, w − 2m, h − 2m)` with `m = 8 + s` and line width `s × 2.2`.
- Create: `scripts/work-art/svg.ts`
  - `simplifyPath(d: string, tolerance: number): string`
  - `plateSvg(d: string): string`
- Test: `tests/work-art-svg.test.ts`

**Interfaces:**
- Produces:
  - `plate(): string` (browser).
  - `simplifyPath(d, tolerance)`: input is `M x yL x y…Z` absolute subpaths. Output is `M x y` followed by `l dx dy` and `z` per subpath, with values on a 0.5 grid.
  - `plateSvg(d): string`: the full SVG document string, background rect plus one path.

- [ ] **Step 1: Write failing tests**
  - `simplifyPath('M0 0L1 0L2 0L3 0Z', 0.15)` returns `'M0 0l3 0z'`.
  - A right-angle path keeps its corner: `simplifyPath('M0 0L10 0L10 10Z', 0.15)` returns `'M0 0l10 0l0 10z'`.
  - Values round to the 0.5 grid: `simplifyPath('M0.26 0L4.74 0Z', 0.15)` returns `'M.5 0l4 0z'`.
  - `plateSvg('M0 0l1 0z')` starts with `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 720 480" width="720" height="480">`. It contains `fill="#16278a"` and `<path d="M0 0l1 0z" fill="#f2f3f7"/>`.
- [ ] **Step 2:** `npx vitest run tests/work-art-svg.test.ts`. Expect FAIL (module missing).
- [ ] **Step 3: Implement `svg.ts`**
  - RDP per subpath, as in `scratchpad/probe/plate-size.mjs`.
  - Rounding is `Math.round(v * 2) / 2`. A leading zero is dropped (`.5`, `-.5`).
  - Each delta comes from the previous *rounded* point, so errors never accumulate.
- [ ] **Step 4:** Rerun the tests. Expect PASS.
- [ ] **Step 5:** Port `engrave.js` and write `plate.js`. Nothing is run yet; Task 3 runs them.

### Task 2: Portrait generator and font embedding

**Files:**
- Create: `scripts/work-art/portrait.js` exporting `portrait(): string`.
  - The B-3 generator from `self-portrait-b2.html`:
    - the `seated` sitter;
    - `filled()` hole fill;
    - whorl eye gap 18;
    - `streams`, `outline` and `face`;
    - `pressure: true`;
    - underpaint `#5c3a1e` at 0.9;
    - seed 63.
  - Serialized with `XMLSerializer`. The root carries width and height.
  - The `<g>` font-family stays `Anybody, 'Noto Sans KR', sans-serif`.
- Create: `scripts/work-art/fonts.ts`
  - `usedText(svg: string): string`
  - `embedFonts(svg: string): Promise<string>`
- Modify: `package.json`. Add devDependencies `playwright-core@1.63.0` and `subset-font@2.9.0` with `npm i -D --save-exact`.
- Test: `tests/work-art-fonts.test.ts`

**Interfaces:**
- Produces:
  - `portrait(): string` (browser).
  - `usedText(svg)`: the set of characters inside `<text>` content, plus a space, sorted and unique. Entities `&amp; &lt;` are decoded.
  - `embedFonts(svg)`: returns `svg` with `<style>` inserted as the root's first child.
    - One Anybody face built from `@fontsource-variable/anybody/files/anybody-latin-standard-normal.woff2`.
    - One face per Noto chunk listed in `@fontsource-variable/noto-sans-kr/wght.css` whose `unicode-range` contains a used character.
    - Every face is subset to the used characters as woff2 and written as a `data:font/woff2;base64,` URL.

- [ ] **Step 1: Write failing tests** on `<svg xmlns="http://www.w3.org/2000/svg"><text>cat 고양이</text></svg>`:
  - `usedText` returns `' act고양이'` (unique, sorted by code point).
  - The output of `embedFonts` contains:
    - exactly one `font-family:'Anybody'` face with `font-weight:100 900` and `font-stretch:50% 150%`;
    - at least one `font-family:'Noto Sans KR'` face with `unicode-range`.
  - The Noto faces' ranges together cover 고, 양 and 이.
  - The output still starts with `<svg xmlns=`.
- [ ] **Step 2:** `npx vitest run tests/work-art-fonts.test.ts`. Expect FAIL.
- [ ] **Step 3:** Install the two dev dependencies. Implement `fonts.ts`, using `subsetFont(buffer, text, { targetFormat: 'woff2' })` with axes kept. If it drops `wdth` or rejects woff2 input, stop and switch to fonttools as the spec allows.
